# SNSアカウントコンセプト：承認済み基準 v0.1

2026-10-14承認。個人・ブランド・事業集客に共通。原本の関連節番号を保持しています。
同じ10項目を使い、参考アカウント分析では観察軸として適用します。モードごとの出力・適用条件はSKILL.mdに従います。

# 3．基本の記録形式

各項目について、次の四つを残します。

| 欄 | 記録するもの |
|---|---|
| 回答 | このアカウントについての具体的な答え |
| 根拠・出典 | 読者の声、行動、既存投稿、取材、実績、資料など |
| 事実／仮説／未確認 | 何を確認し、何を解釈し、何が分からないか |
| 不足時の確認方法 | 誰に何を聞くか、どの投稿・指標で何を確かめるか |

「事実」は確認できた範囲に限ります。数字があることだけで、その背後の心理や因果関係まで事実にしません。合成人物を実在の一人への調査として扱いません。

# 4．作る手順と完成案チェック

以下の順番で考えます。新しい根拠や矛盾が見つかったら、前の項目へ戻って構いません。

| 順番・項目 | 作るときの問い | 完成案の合格条件 |
|---|---|---|
| **① 目的** | このアカウントで何を実現したいか | 主目的と、成果として観測するものが書かれている |
| **② 対象者** | 最初に誰に届けたいか。その人はどんな状況か | 年齢・性別だけでなく、関心・状況・利用場面で説明できる |
| **③ 欲求・関心** | 相手は何を知りたい、感じたい、楽しみたいか | 相手の声・行動などの根拠がある。なければ仮説と明記されている |
| **④ 競合・代替** | 相手は今、どこで同じ価値を得ているか | 他アカウント・検索・別メディア等と比べ、選ぶ理由を説明できる |
| **⑤ フォローする価値** | 一つの投稿を見るだけでなく、継続して見る理由は何か | 今後どんな価値が繰り返し届くかが具体的。「役立つ」「面白い」だけで終わっていない |
| **⑥ 発信者との適合** | なぜ自分・このブランドが届けられるのか | 経験・取材先・技術・視点・表現力など、実際に使える材料がある |
| **⑦ 投稿への具体化** | その価値を、どんな投稿で届けるか | コンセプトから具体的な投稿案が作れ、各案が提供価値につながる |
| **⑧ 一貫性と範囲** | 何を扱い、何を扱わないか | プロフィールと代表投稿が同じ期待をつくる。扱わない領域も分かる |
| **⑨ 継続可能性** | 情報・素材・時間・費用を継続して確保できるか | 制作の流れと工数を見積もれ、無理のない発信頻度を説明できる |
| **⑩ 検証** | 想定した相手に価値が届いたか、どう確かめるか | 検証期間・主指標・見直す条件が決まっている。反応の大きさだけで判断しない |

## 4-1．混同しないもの

- 発信者の目的と、見る人にとっての価値。
- 投稿を一度見る理由と、アカウントを継続して見る理由。
- 顧客の欲しい成果と、発信者が裏付けを持って約束できる成果。
- 競合にないことと、相手が選ぶ理由。
- コンセプトの一貫性と、形式を一種類に固定すること。
- フォロワー数・表示回数と、主目的の達成。
- アカウントの試行可能性と、投稿・公開の操作許可。

# 5．目的別チェック

目的は複数あっても構いません。ただし、最初の検証では主目的を一つ置きます。販売目的でないアカウントに、購入導線を必須にはしません。

| 主目的 | 追加で確認すること |
|---|---|
| **認知・ブランド** | 誰に、何の存在として覚えてほしいか。投稿からその印象が伝わるか |
| **信用・専門性** | 専門性や判断の質を、実例・根拠・考え方で示せるか |
| **販売・集客** | フォロワーと購入者がどうつながるか。商品への案内で期待がズレないか |
| **学習・情報提供** | 相手の理解・判断・行動がどう助けられるか。情報の正確さを保てるか |
| **娯楽・共感** | どんな楽しさ・感情・共感が得られるか。それを繰り返し届けられるか |
| **交流・コミュニティ** | 誰と、何について関わる場か。参加しやすさと安全な運営を設計できるか |

目的別の具体的な指標・目標値・期限は、個々のアカウントを設計するときに定めます。共通のフォロワー数や売上の合格点は置きません。

# 6．判定ルール

## 6-1．要修正

次のような状態は、点数や見栄えで埋め合わせず、修正します。

- 対象者と提供価値のつながりが説明できない。
- プロフィールと実際の投稿で、期待がズレる。
- 裏付けのない実績・成果を約束している。
- 必要な素材・権利・制作能力を確保できない。

## 6-2．試行可能

- 一貫したコンセプトと具体的な投稿案がある。
- 続けられる見通しがある。
- 未確認の仮説と、その検証方法が明記されている。

新規アカウントで実績がなくても、仮説として試せます。ただし、仮説を確認済みの効果として表現しません。

## 6-3．効果を確認

- 実際に運用し、事前に定めた条件を満たす結果が観測されている。
- 結果の範囲と限界も記録されている。

特定条件での観測結果を、別媒体・別対象・将来の成功保証へ広げません。

# 7．投稿による具体化と出力

## 7-1．具体化の仮基準

- **投稿ネタ10件**を作る。
- その中から**代表投稿の短い案3件**を作る。
- 各投稿が、対象者にどの提供価値を届けるか照合する。
- プロフィールがつくる期待と、代表投稿が実際に届けるものを照合する。

10件と3件は、抽象的な言葉で終わらせないための確認用です。公式の成功基準や、実運用の投稿頻度ではありません。

## 7-2．コンセプトの一文

> **誰に、どんな情報・体験・感情を、どんな視点や方法で継続して届けるアカウントか。**

この一文は、合格条件の代わりではありません。共通10項目の内容を短く説明するために使います。

## 7-3．完成案として残すもの

- コンセプトの一文。
- 共通10項目の回答・根拠・事実／仮説／未確認・確認方法。
- 主目的に応じた追加チェック。
- 投稿ネタ10件と代表投稿の短い案3件。
- 全体判定と、その理由。
- 未確認の仮説、確認方法、見直す条件。
