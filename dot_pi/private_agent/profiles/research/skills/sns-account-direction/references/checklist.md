# ディレクションシートの確認軸

## 設計の具体性

| 項目 | 残すもの |
|---|---|
| コンセプト | 対象者・利用場面・継続価値・届け方の一文。見る人と発信者の目的は別 |
| 世界観 | 見る人が感じること、比喩、繰り返し使う表現、その理由 |
| 発信者・顔 | 実際の資源／架空のキャラ設定／名乗れない資格や体験の区別 |
| 語り口 | 見出し・短文の実例、距離感、断定の範囲、避ける誘導 |
| 見た目 | 色、文字の強弱、余白、図・写真・アイコンの役割、情報と広告の区別 |
| 投稿の柱 | 各柱が継続価値にどう寄与するか。テーマと形式を区別 |
| 形式・頻度 | 静止画・動画等の役割、仮頻度、制作・更新・検品を含む時間 |
| 媒体の使い分け | 同じ約束を維持しつつ、各媒体の見せ方・誘導を調整 |
| 範囲 | 扱うこと／扱わないこと。広告関係・出典・未確認の見せ方 |
| 検証・引き渡し | プロフィールとの一致、制作要件、読者の受け取り方と成果の観測 |

これはディレクションを具体化する観点であり、既存コンセプトの共通10項目に代わる合格基準ではない。

## 具体例

非販売の地域文化紹介なら、公開資料を図解する編集者、生成り背景・藍色見出し・自作道具図、「この資料では…」の語り口、季節・言葉・道具の柱という案がある。
その地域の歴史をAIが創作したり、現地経験者として語ったりはしない。送客目的の案では、比較表と確認質問を中心に、紹介先と関係性・対象外を明示する。販売しない案に購入導線は必須でない。

## 確認と見直し

具体案の数と既存点検の方法は `../sns-account-concept/` の正本で読む。資料が不足した状態で合格項目を記憶から再構成しない。
「世界観が整った」「反応が多い」「AIで作れる」は、継続価値・送客成果を確認したこととは別。制作工数、正確性、読者の具体的な反応、目的の成果を分けて観測する。
参考分析は他者の表現を複製する指示にせず、転用条件を残す。
