# AI実現制約の確認軸

## 1．要件と状態

| 状態 | 判断に必要な証拠 |
|---|---|
| 対応可能 | 対象用途・品質・利用条件・実環境で検証した証拠。確認範囲と限界を付ける |
| 条件付き | 具体的な成立条件と担当・確認方法がある。未確認の条件を満たした扱いにしない |
| 未確認 | 必要な証拠がない。理由、確認範囲、次の確認・保留条件を示す |
| 現条件では不可 | 予算・時間・利用条件等との明確な不一致を根拠に示す。全環境で不可能へ拡大しない |

同じ要件でも技術・利用許可・本人環境・費用の状態は異なる。全体の3判定と要件別4状態を混ぜない。

## 2．確認する軸

| 軸 | 確認 |
|---|---|
| 情報 | 出典、日付、適用範囲、固有名詞・数字、更新・検品担当。生成文を事実の証拠にしない |
| 文字・図 | 日本語文字、改行・あふれ・可読性、比較条件・矢印と本文の一致 |
| 人物・動画・音声 | 参照素材の権利、一貫性、動き・発話・字幕、許容差、実在人物の誤認 |
| 権利・規約 | 商用利用、加工・SNS公開、音声・BGM・素材、広告・AI表示、地域・業種条件 |
| 本人環境 | アカウント種別・資格・権限・認証・API条件、公開・計測可能な形式、実際の利用可否 |
| 継続運用 | 独自素材の供給、初期準備、再生成、検品、修正、保管・公開・計測、障害と停止 |
| 費用・時間 | 失敗分・固定費・税等と人の作業を含む総額。予算上限と実支出を分ける |

自動化の存在は完全無人運用の証明ではない。本人確認・認証・公開承認・権利判断をAIに代行させる設計にしない。

## 3．費用・試験

```text
月の現金費用 = 生成試行数×試行単価 + 固定費 + 音声・合成・保管・公開・計測費 + 税等
人の時間 = 初期準備・試験 + 素材・本文確認 + 検品・修正 + 承認・計測 + 障害対応
```

例：1生成100円で毎日1本なら、30日一発成功で3000円。31日は3100円。再生成・合成・確認に余裕がない。「単価100円」は合格品100円とは違う。
固定画像＋別工程の日本語テロップ、無音・静止画主体、投稿頻度の見直しは候補。無音でも人物画像の権利・表示・人の検品・公開資格は残る。代替の読者価値・売上維持は未検証なら別論点。

試験例（提案）：権利確認後、想定する日本語・人物の角度が違う3本を非公開で作る。各素材の出典・文字を人が照合し、意味の誤り・欠字・人物の許容差・総費用・作業分数を記録。合格基準は先に固定。限られた試験の成功を将来全投稿の保証にしない。
課金・生成・公開を伴う試験は、その対象と費用・影響を示した別承認後に行う。
