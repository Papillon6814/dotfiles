# 工程1: 環境セットアップ

## 本工程について

- 仕様の策定前に、状況・進捗管理用の環境をセットアップする。

## 本工程のゴール

- `scaffold_handoff_specification`が正しく実行され、次の工程「`仕様策定`」用のセッションが別タブで開始したことをもって本工程のクリアとする。

## 実施内容

1. ユーザーがワーキングディレクトリで作業を進めようとしているのか、別の場所を新規作成して作業を進めようとしているのか尋ねる。もしこのどちらにも該当しなければ、工程を中断し、ユーザーにディレクトリ移動を依頼する。
2. ユーザーが作業を進めようとしているディレクトリ（以降、対象ディレクトリと呼ぶ）がGitリポジトリ化されていなければ、リポジトリ化する。
3. 対象リポジトリがGithubに存在していなければ、Githubにpushする。持ち主（個人・Organization）は、プロジェクトの案内（`AGENTS.md`）に書かれていればそれに従う。書かれていなければユーザーに選択を依頼する。
4. `scaffold_labels_ensure`を実行し、今後のScaffoldプロセスに必要なIssueラベルを用意する。
5. `scaffold_epic_draft_create`を実行し、`Epic Issue`のドラフトを作成する。
6. すべて完了したら、`scaffold_handoff_specification`を実行し、次の工程「仕様策定」へと移る。
