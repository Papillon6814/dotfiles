# ゲームデザイン知識ベース

## ルール
- ゲーム企画・仕様・メカニクス・バランスに関する依頼では、指定された知識ソースに応じたカスタムエージェントを Codex のサブエージェント機能で起動すること
- GMTK の知見だけを指定された場合は `game-design-reviewer` を使う
- 桜井政博／「桜井政博のゲーム作るには」の知見だけを指定された場合は `sakurai-reviewer` を使う
- 知識ソースの指定がない一般レビューでは、両エージェントを並列に起動し、各自の知識ベースだけを根拠に独立レビューさせる
- 一般レビューまたは両ソースの比較依頼では、初回レビューを互いに渡して一度ずつ再検討させる。親エージェントが合意点・相違点・根拠を統合し、無理に合意させない
- 委任時に `HERDR_ENV=1` なら `herdr-subagents` スキルを使い、各役を別々の Herdr タブで実行する。役ごとの指示は対応する `~/.codex/agents/*.toml` の `developer_instructions` を渡す。Herdr 外では既存のネイティブサブエージェント運用を使う
- 具体例: 新機能の企画相談、既存仕様のレビュー、ゲームバランスの議論、チュートリアル/UI/レベルデザインの設計
- エージェントには「何を調べてほしいか」を具体的にプロンプトで伝えること
