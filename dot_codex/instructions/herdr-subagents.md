# Herdr での Codex サブエージェント

サブエージェントへ委任する時、現在の Codex セッションが Herdr 管理下（`HERDR_ENV=1`）なら、ネイティブの非表示子スレッドではなく `herdr-subagents` スキルを使い、子ごとに Herdr タブを作成して独立した Codex セッションを起動する。各子へ作業に必要な依頼・会話上の文脈・カスタムエージェントの役割指示を渡し、Herdr の出力を読み取って親の回答へ統合する。作成したタブはユーザーが見たり直接話したりできるよう開いたままにする。

Herdr 外では Herdr の制御コマンドを実行せず、通常の Codex サブエージェントを使う。ユーザーが可視の Herdr タブを明示している場合は、現在のセッションが Herdr 管理下にないことを伝える。
